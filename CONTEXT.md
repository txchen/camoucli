# Camoucli

Camoucli is a Node.js-first CLI and local daemon for driving Camoufox through Playwright.

## Language

**Local Browser Automation CLI Parity**:
Compatibility with `agent-browser` command-line workflows that can run through Camoucli's local Camoufox/Playwright daemon without adopting unrelated product surfaces.
_Avoid_: Full Agent Browser product parity, provider parity
