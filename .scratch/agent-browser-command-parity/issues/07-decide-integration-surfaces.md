# Decide Integration Surfaces

## Question

Should Camoucli pursue any `agent-browser` integration surfaces beyond browser automation command parity?

Decide the fate of MCP, dashboard, chat, plugin management, skills management, install/upgrade analogs, provider abstractions, and Node API parity. If any are accepted, define the minimum scope needed for Camoucli rather than copying `agent-browser` wholesale.

## Answer

Ruled out of scope by [Decide Parity Scope Boundaries](02-decide-parity-scope-boundaries.md).

This effort is limited to Local Browser Automation CLI Parity. Agent Browser integration surfaces such as `mcp`, `dashboard`, `chat`, `plugin`/`plugins`, `skills`, and provider abstractions should be handled as separate future efforts if needed.
